# 武汉市土地利用时空信息服务平台

> 现代空间信息系统软件工程课程作业 · 樊文有老师 · 2026 秋
> 自选场景:武汉市土地利用时空信息服务平台(Web 部署形态)

## 一、项目简介

围绕武汉市 2003/2005/2010/2013 四期 30m 分辨率土地利用数据(30m×30m,7 类,EPSG:32649),
构建一个 Web 时空信息服务平台,提供:

- **v1(及格线)**:网页地图浏览、4 期土地利用图层切换对比、面积统计查询(框选/行政区 → 各地类面积)
- **v2(加分项)**:PLUS 模拟结果图层(未来情景)、ECharts 统计图表、专题出图

## 二、技术栈

| 层 | 技术 |
|---|---|
| 前端 | HTML/CSS/JS + Vue 3 + Leaflet |
| 后端 | Python FastAPI |
| 数据库 | PostgreSQL + PostGIS |
| 版本管理 | Git + GitHub |

## 三、目录结构

```
wuhan-landuse-platform/
├── docs/          # 五件套文档(需求/设计规格说明书等)
├── frontend/      # Vue 3 + Leaflet 前端
├── backend/       # FastAPI 后端
├── database/      # PostGIS 建库脚本、数据导入脚本、导出
└── data/          # 数据文件清单(原始 tif 不入库版本管理,仅存清单)
```

## 四、快速启动

> 待第 4-5 周前后端联调后补全(数据库初始化 → 后端启动 → 前端启动)。

## 五、数据说明

- 原始数据:武汉市土地利用 4 期栅格(2003/2005/2010/2013),2931×2931,30m 分辨率,7 类,EPSG:32649
- 入库策略:rasterio 按行政区/网格聚合统计,写入 PostGIS 空间表;前端不直接加载全分辨率栅格
